- Battery Status, Cleaner, Password Generator, QR Generator & More
- Works on Samsung, Xiaomi, Motorola, Pixel, OnePlus - ANY Android

### Install on ANY Android
1. Install Termux & Termux:API from F-Droid
2. Run:
bash
pkg update && pkg install termux-api neofetch yt-dlp mpv git qrencode -y
termux-setup-storage
git clone https://github.com/Lexnorths-commits/android-control-center.git
cd android-control-center
chmod +x android_control.sh
./android_control.sh
